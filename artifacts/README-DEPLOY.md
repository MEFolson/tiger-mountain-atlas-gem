# Cush website

TanStack Start + Vite + Tailwind. Dual product: Cush Payments and Cush Core.

## Run locally

```bash
npm install
npm run dev
```

Dev server: `http://localhost:8080`

## Production build

```bash
npm run build
npm run preview
```
